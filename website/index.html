FEATURES

把该有的都有，
把不该有的都删了。

语法高亮 · 24 种语言

Sourceful 词法分析引擎，不是正则涂色。VS Code Light+ / Dark+ 两套配色，随系统深浅色自动切换。

SwiftRustPythonTypeScriptGo+ 19 种

Markdown 实时预览

右侧分栏，边写边渲染，250ms 防抖。标题、表格、代码块、图片、链接通通支持。

中文编码自动检测

UTF-8 / UTF-16 / GBK / GB18030 逐层嗅探，保存时按原编码写回。打开老文件，不乱码。

自动保存

编辑即写回原文件，掉电也不丢一个字。⌘S 可以退休了。

SVG / HTML 预览

只读 WebView 原样渲染，禁用 JavaScript——省内存，也更安全。

默认打开方式

声明 60+ 种文本与代码类型，一条命令接管整个系统的默认打开方式。

100% 原生，不是套壳

TextKit + NSDocument + SwiftUI 承载，没有一行 Electron。所以才敢说：冷启动 214ms、常驻 43MB、包体 836KB。

深浅色主题，跟随系统

白天 VS Code Light+，夜里 VS Code Dark+，Mote 随系统外观自动切换——包括这个网页。
