Mote 使用指南

极致轻量的 macOS 原生文本编辑器:
快,是打开速度优先的那种快。

核心特性

  • 冷启动 214ms,常驻 43MB
  • 安装包只有 836KB
  • ⌘S 已经不需要了
  • 深浅色主题跟随系统

打开,即编辑。

编码自动检测

UTF-8 / UTF-16 / GBK / GB18030,
保存时按原编码写回,不乱码。

编码支持
UTF-8✓
GB18030✓
 
final class MoteDocument: NSDocument {
    override func save(to url: URL) throws {
        try text.write(to: url,
                encoding: encoding)
    }
}
