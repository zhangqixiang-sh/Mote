# Mote 使用示例

> 一款极致轻量的 macOS 文本编辑器

## 特性

- **语法高亮**:24 种语言
- *主题*:深浅色跟随系统
- `Cmd+S` 快速保存

## 性能目标

| 指标 | 目标 |
|------|------|
| 冷启动 | < 300ms |
| 常驻内存 | < 80MB |

代码示例:

```swift
let editor = MoteEditor()
editor.open(file: "README.md")
```
