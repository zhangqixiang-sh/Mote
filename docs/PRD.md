# Mote PRD v0

> 创建日期:2026-08-25 | 状态:规划已确认,待实现
> 产品:macOS 轻量文本编辑器「Mote」

## 一、产品定位

一款**极致的轻量 macOS 文本编辑器**:打开速度优先、内存占用最低、纯原生体验,同时具备代码高亮、Markdown 右侧预览、SVG 渲染预览。作为 json / yaml / md / 各类代码文件的默认打开程序。

一句话:**CotEditor 的底子(原生极速)+ 一等公民的渲染预览(Markdown / SVG)**。

## 三、技术决策(已确认)

| # | 决策项 | 结论 |
|---|--------|------|
| 1 | 技术栈 | 纯原生:SwiftUI/AppKit + TextKit(`NSTextView`),不用 Electron/Tauri |
| 2 | App 骨架 | **NSDocument(AppKit)承载 + SwiftUI 渐进引入**;不做"最近文件"功能 |
| 3 | 架构分工 | 编辑区 100% 原生;预览面板 = 只读 WKWebView,**懒加载、按需创建、关闭即释放** |
| 4 | 统一预览面板 | 按文件类型路由:`.md` → Markdown 渲染器;`.svg` → 直接加载;`.html` → 直接加载 |
| 5 | 高亮引擎 | Sourceful(加载 VS Code TextMate 语法 + 主题),内置 20~30 种常见语言 |
| 6 | 编码检测 | 第一期实现,参考 CotEditor 的嗅探思路 |
| 7 | Markdown 预览范围 | 第一期:基础渲染(标题/列表/表格/代码块/图片/链接,边输入边刷新);KaTeX/Mermaid/滚动同步 → 第二期 |
| 8 | SVG 预览 | 默认静态渲染(关 JS) |
| 9 | 文件类型注册 | json / yaml / md / plain-text / 常见代码扩展名;`LSHandlerRank: Alternate`(备选,不抢 Xcode/VS Code 默认) |
| 10 | 多标签 / 最近文件 | **不做**(第一期及默认形态) |
| 11 | 分发 | 第一期自用:本地 ad-hoc 签名,无需开发者账号 |
| 12 | macOS 最低版本 | **macOS 14 Sonoma+** |
| 13 | 实现路线 | **参考 CotEditor 开源源码做架构参考,独立实现**(不 fork、不复制代码) |

## 四、性能目标(可量化验收)

| 指标 | 目标 |
|------|------|
| 冷启动到窗口可见 | < 300ms |
| 双击文件打开到可编辑(≤ 5MB) | < 500ms |
| 常驻内存(单窗口) | < 80MB |
| 安装包体积 | < 10MB |

工程手段:启动零阻塞(文件解析/高亮后置)、预览面板懒加载、按可见区域渲染。

## 五、非目标(第一期明确不做)

- 大文件专项优化(100MB+)
- 代码补全 / 插件 / 命令面板 / 文件树
- Markdown 公式、Mermaid、滚动同步
- SVG 动态脚本
- 多标签页
- 最近文件列表
- 对外分发(公证)

## 六、里程碑

| 里程碑 | 内容 | 验收 |
|--------|------|------|
| M1 | 工程骨架:NSDocument 打开/保存/明文编辑 | 双击文件秒开,可编辑可保存 |
| M2 | 语法高亮(Sourceful)+ 主题系统(深浅色跟随系统) | 20~30 种语言正确高亮 |
| M3 | Markdown 右侧分栏预览(懒加载 WebView) | 边输入边刷新,基础语法正确渲染 |
| M4 | 打磨:SVG 预览、编码检测、自动保存、文件关联、性能达标、签名 | 全部性能指标达标 |

## 七、工程约定

- 工程生成:XcodeGen(`project.yml` 为工程唯一事实来源,`.xcodeproj` 不手工编辑)
- 最低系统:macOS 14.0
- 代码签名:本地 ad-hoc("Sign to Run Locally")
- 模块目录预留:`App/` `Documents/` `Editor/` `Highlighting/` `Preview/` `Encoding/`
- 提交规范:PRD 与工程骨架为初始提交;之后按里程碑原子提交
